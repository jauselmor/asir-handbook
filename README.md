# par-handbook

Material del módulo **0370 Planificación y Administración de Redes** del CFGS
de Administración de Sistemas Informáticos en Red. Sitio MkDocs bilingüe
(inglés como fuente de verdad, español obligatorio) publicado en GitHub Pages,
con un backend docente fuera del build.

```bash
uv sync
./init.sh          # verificación completa
uv run mkdocs serve
```

El repositorio no es sólo el sitio: es un arnés de trabajo. Empieza por
`AGENTS.md`.
